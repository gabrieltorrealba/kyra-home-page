# 🐕 Kyra - Página de Mascota Perdida

Página web móvil para ayudar a encontrar a Kyra, una perrita mestiza de 6 años que se perdió en Buenos Aires, Argentina.

## 🌟 Características

- **Diseño Mobile-First**: Optimizado para dispositivos móviles
- **Contacto directo**: Botones de WhatsApp para contactar a los dueños
- **Galería de fotos**: Múltiples fotos de Kyra para identificarla fácilmente
- **Información clara**: Datos de la mascota visibles inmediatamente

## 📱 Uso

1. Escanea el código QR en el collar de Kyra
2. Verás esta página con fotos e información
3. Toca el botón de WhatsApp para contactar a los dueños

## 🛠️ Tecnologías

- HTML5
- CSS3 (Tailwind + Custom CSS)
- JavaScript Vanilla

## 📂 Estructura

```
├── index.html      # Página principal
├── main.js         # Lógica JavaScript
├── assets/
│   ├── style.css   # Estilos personalizados
│   └── img/        # Imágenes de Kyra
```
